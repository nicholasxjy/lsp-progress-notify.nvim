INTRODUCTION                                            *lsp-progress-notify-introduction*

lsp-progress-notify.nvim shows LSP progress using native Neovim floating
windows.

It is implemented on top of Neovim 0.11+ |LspProgress| autocmds and updates the
same notification for each progress token across the begin/report/end phases.

==============================================================================
REQUIREMENTS                                            *lsp-progress-notify-requirements*

- Neovim >= 0.11
No external notification plugin is required.

This plugin does not support Neovim 0.10 or older.

==============================================================================
INSTALLATION                                            *lsp-progress-notify-installation*

Example with lazy.nvim: >lua
  {
    "nicholasxjy/lsp-progress-notify.nvim",
    config = function()
      require("lsp-progress-notify").setup()
    end,
  }
<

==============================================================================
SETUP                                                          *lsp-progress-notify-setup*

Call `setup()` once: >lua
  require("lsp-progress-notify").setup()
<

If Neovim is older than 0.11, `setup()` throws an error.

==============================================================================
CONFIGURATION                                        *lsp-progress-notify-configuration*

Default configuration: >lua
  require("lsp-progress-notify").setup({
    enabled = true,
    spinner_interval = 120,
    icons = {
      spinner = { "⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏" },
      done = "",
    },
    messages = {
      complete = "Completed",
      detached = "Detached",
      working = "Working…",
    },
    notification = {
      ongoing_timeout = false,
      done_timeout = 2000,
      min_width = 32,
      width = 44,
      max_width = 56,
      max_height = 12,
      row = 1,
      col = 2,
      spacing = 1,
      border = "rounded",
      zindex = 50,
      winblend = 0,
      on_open = nil,
      on_close = nil,
    },
    title = function(client_name, task)
      return client_name
    end,
    format = function(client_name, task)
      -- Return notification body text
    end,
  })
<

Options overview:

  enabled                                  Enable on setup.
  spinner_interval                         Spinner refresh interval in ms.
  icons.spinner                            Spinner frames.
  icons.done                               Icon used after completion.
  messages.complete                        Fallback completion message.
  messages.detached                        Message used on |LspDetach|.
  messages.working                         Fallback in-progress message.
  notification.ongoing_timeout             Timeout while task is active.
  notification.done_timeout                Timeout after completion.
  notification.min_width                   Minimum floating window width.
  notification.width                       Preferred floating window width.
  notification.max_width                   Maximum floating window width.
  notification.max_height                  Maximum rendered content lines.
  notification.row                         Top offset for the first window.
  notification.col                         Right offset for windows.
  notification.spacing                     Lines between stacked windows.
  notification.border                      Floating window border style.
  notification.zindex                      Floating window z-index.
  notification.winblend                    Floating window blend value.
  notification.on_open                     Open callback for floating windows.
  notification.on_close                    Close callback for floating windows.
  title(client_name, task)                 Notification title callback.
  format(client_name, task)                Notification body callback.

==============================================================================
HEALTH                                                        *lsp-progress-notify-health*

Run: >vim
  :checkhealth lsp-progress-notify
<

The health check reports:

- whether Neovim is at least 0.11
- whether the built-in floating window backend is available
- whether plugin user commands are registered

==============================================================================
COMMANDS                                                    *lsp-progress-notify-commands*

:LspProgressNotifyEnable
    Enable progress notifications.

:LspProgressNotifyDisable
    Disable progress notifications and clear tracked state.

:LspProgressNotifyToggle
    Toggle progress notifications.

==============================================================================
API                                                              *lsp-progress-notify-api*

>lua
  local progress = require("lsp-progress-notify")

  progress.setup(opts)
  progress.enable()
  progress.disable()
  progress.is_enabled()
  progress.status()
<

`status()` returns a snapshot of currently tracked tasks.
